# Changelog

What changed in each version of Toddler Camera. The newest is at the top.
Each build uses the "Next" section as its release notes on GitHub, then renames it to the new version.

## Next

- (nothing yet)

## v0.1.9

- Updates now install without Android's extra "Update?" screen (Android 12 and later). The first update after this one still asks once; after that the app just closes and you open it again on the new version
- Builds are now release builds (signed with the same key, so they install over this one), which should mean fewer Google Play Protect warnings

## v0.1.8

- App updates now work the same way as in the other toddler apps. The app quietly checks for a new version (when the parent area opens, and at most every 6 hours otherwise) without popping anything up
- When there is a new version, "App updates" in the parent settings turns red and says which version is ready
- New versions screen: new versions with what changed at the top, then the installed version, then older versions behind "Show older versions", with a way to go back to one and to reinstall the current one

## v0.1.7

- In-app updates from the parent area

## v0.1.6

- README updated

## v0.1.5

- New app icon

## v0.1.4

- Optional white screen flash when a picture is taken
- The gallery button can show the last picture taken
- Choice of shutter sounds

## v0.1.3

- Parent settings behind a PIN: switch features on or off, gallery options, camera and video options, sounds, saving location and a play time limit

## v0.1.2

- Buttons and icons are now drawn by the app, so they look the same on every phone

## v0.1.1

- First version: take pictures and videos with the front or back camera, a simple gallery and an optional toddler lock
